SprintPilot full RAG pipeline — ingestion and retrieval phases, technology used and design rationale for each step

Ingestion — offline, once per document
1Raw document
PDF, DOCX, MD, JSON, HTML, PPTX
6 formats, one unified downstream pipeline
2Detect doc type
metadata["type"] first → path keywords: sprint/adr/slack/ticket/jira → default "doc"
Zero-cost routing — source folder is a reliable signal, no LLM call needed
3Resolve chunk strategy
ChunkingStrategyFactory → chunking.yaml hot-reload (ext > doc_type > fallback)
Extension is a hard guarantee — .pdf is always rich_document regardless of metadata
4Parse document
3 paths by split_method from resolved strategy:
Slack JSON
load_slack_json()
msg-per-chunk
unstructured.io
partition() typed elements
pypdf fallback
Plain text / MD
Path.read_text()
para-aware split
PDF also: extract_pdf_images() → Tesseract OCR → image chunk with image_path + ocr_text
Each format has structure that naive text extraction destroys; images become searchable and viewable
5Filter + quality gate
TOC filter (>25% dots) · _is_noise_title() (code, pipes, colons, all-caps) · _has_meaningful_content() (≥5 words >2 chars)
Dot-leaders and bold labels become junk chunks that poison search results
6Parent-child split
~2000t parents (~8000 chars) / ~512t children (~2048 chars) / 50t overlap · _find_break_point() at sentence → para → word
2025 benchmark: 0.88/0.85 P/R vs 0.78/0.72 flat — search small for precision, read large for full context
7LLM context prefix
Groq llm · 1–2 sentence chunk summary · 3 retries (2s→4s backoff) · batch throttled with BATCH_SLEEP
Anthropic 2024: −35% retrieval failures standalone; −49% combined with hybrid BM25
8Batch embed
prefix + child text → all-MiniLM-L6-v2 · 384-dim · batch_size=32 · normalize=True · local, no API
Local = zero cost and latency; batch_size=32 is ~5× faster than one-by-one; consistent space
9Qdrant upsert
Child: UUID5(content) dedup · Parent: is_parent=True excluded from search · metadata: section_title, page_no, element_type, chunk_index, document_position, ingested_date, prev/next_chunk_id, parent_id
Parents excluded so they don't compete with children; rich metadata enables pre-filter narrowing
10Cross-doc link build
search_related() per chunk · min_score=0.75 · different source only · writes related_chunk_ids back via update_payload()
Enables cross-source correlation at query time without duplicating any chunk
Retrieval — online, per query
1User query
Raw natural language query string from agent
Triggers full pipeline or the recall shortcut at step 2
2Recall mode check
identify_document() → semantic probe → title-overlap scoring (vs pure top-chunk bias) → retrieve_full_document() in chunk_index order
"Show me the whole checklist" needs all chunks ordered, not top-7 fragments
3Embed query
embed_text() · all-MiniLM-L6-v2 · normalize=True (same model as ingestion)
Consistent vector space — different models at query vs ingest time breaks similarity scores
4Qdrant pre-filter
project + stale=False + optional doc_types · applied inside Qdrant before vector search (not post-filter)
Removes wrong-project chunks before expensive similarity math, not after
5Vector search
Qdrant cosine similarity · top-30 candidates · is_parent=True excluded
Semantic match: "DB keeps crashing" finds "connection pool timeout"; 30 gives reranker headroom
6BM25 keyword search
BM25Okapi on same 30-doc corpus · query.lower().split() · rank_bm25 library
Exact match: "SDLC-1042", "/api/v2/auth", "nginx" that embedding similarity misses
7Reciprocal rank fusion
RRF(d) = Σ 1/(k+rank) · k=60 (Cormack et al. 2009) · rank-based, not score-based
Vector cosine and BM25 scores live on different scales; ranks are scale-independent
8Cross-encoder rerank
ms-marco-MiniLM-L-6-v2 · CrossEncoder.predict() · sigmoid(x/3) temperature T=3
Reads query+doc together (not approximate); T=3 corrects domain gap (web-trained on sprint docs)
9Top-7 selection
Sorted by reranker score desc · top_k=7 from config · builds RetrievedChunk(text, parent_text, source, doc_type, score, metadata)
Quality ceiling — reranker picks most genuinely relevant, not just most similar
10Confidence tier
≥0.75 HIGH · 0.45–0.74 MEDIUM · 0.20–0.44 LOW · <0.20 NO_EVIDENCE
Agents add caveat language at MEDIUM/LOW; below 0.45 triggers corrective retry
Corrective RAG loop (if <0.45)
llm_rewrite_fn(query) → reformulated retry → best of {first_pass, corrective, degraded} returned
Reformulates bad queries rather than silently returning weak evidence to the agent
11Parent chunk swap
RetrievedChunk.parent_text (~2000t) replaces .text child (~512t) — denormalized in Qdrant payload, single lookup
Search small for precision; LLM reads large for full surrounding context
12Agents receive
list[RetrievedChunk] + float confidence_score + strategy_used (first_pass/corrective/degraded)
Score calibrates answer certainty; strategy_used surfaces retrieval quality in agent logs
